# Contributing

Contributions are welcome — bug reports, fixes, docs, and small features.

There’s no formal process. Open an issue or pull request if something looks useful.

## Getting started

Requirements and run commands are in the [README Development](./README.md#development) section.

For how the product is structured, start with [`CLAUDE.md`](./CLAUDE.md).

## A few notes

- Draft is alpha; expect change.
- Prefer focused PRs over large ones.
- Don’t hand-edit generated `frontend/wailsjs` bindings.
- Line endings in-repo are LF (Windows `.ps1` / `.bat` / `.cmd` keep CRLF).
